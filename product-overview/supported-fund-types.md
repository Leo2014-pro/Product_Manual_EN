# Supported Fund Types

### Fiat Currency Rail

- USD / EUR / GBP / SGD / HKD
- Bank transfers
- SWIFT network
- Card payment networks (Visa / Mastercard)

### Digital Asset Rail (Crypto Rail)

- Major cryptocurrencies such as USDT / USDC / BTC / ETH
- Multi-chain addresses (TRC20 / ERC20, etc.)
- On-chain collection and transfers
- Automatic crediting and ledger mapping
