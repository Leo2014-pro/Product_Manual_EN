# Core Capabilities

The platform provides six foundational capability systems:
- 🌐 Global Collection System (Inbound Rails)
- 💳 Global Payment System (Card Acquiring)
- 🏦 Virtual Account System (VA + Ledger)
- 💳 Crypto Card System
- 🔄 Settlement and Exchange System (Settlement Layer)
- 🔌 Channel Routing System (Routing Engine)
