# Settlement and Exchange


### Module Definition

Used for handling conversions between different fund systems.

### Dual-Mode Settlement

**Compliant Settlement Mode**
- Licensed institution handles exchange
- Cross-border fiat settlement
- Standard clearing path

**Fund Pool Mode**
- Internal liquidity system
- Stablecoin bridging
- Real-time exchange

### Example (Cross-System Flow)

USD deposit → USD/USDT OTC → USD withdrawal
