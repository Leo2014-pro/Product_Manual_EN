# Crypto Card


### Module Definition

Used for issuing global payment cards that connect to spending networks.

### Capabilities

Supports:
- Virtual Card
- Physical Card
- Visa / Mastercard networks
- Real-time card issuance / freeze / unfreeze
- Limit controls (Daily / Monthly Limit)

### Example (Ad Spending)

- User deposits USDT
- Converts to USD
- Generates a Visa card
- Used for Google / Meta ad spending
- Real-time deductions and records
