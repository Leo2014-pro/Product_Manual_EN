# Merchant Center

The Merchant Center is the core operational backend of the platform, covering all functional modules including asset management, collections, payouts, crypto card issuing, OTC, VA accounts, card acquiring, reports, system administration, and developer integration.

## Functional Modules

| Module | Document | Description |
|--------|----------|-------------|
| Asset Center | [asset-center.md](asset-center.md) | Asset accounts, deposits/withdrawals, transfers, beneficiary management, fees, OTC |
| Collection | [collection.md](collection.md) | Payment links, crypto collection orders, fiat collection orders |
| Payout | [payout.md](payout.md) | Crypto payout orders, fiat payout orders |
| OTC Orders | [otc-orders.md](otc-orders.md) | OSL OTC accounts, collections, payouts, counterparties, order management |
| UCard Management | [ucard-management.md](ucard-management.md) | UCard accounts, shared projects, card management, 3DS verification, transaction inquiry, cardholders |
| VA Account | [va-account.md](va-account.md) | User management, account management, transaction inquiry, verification records, creation records |
| Card Acquiring | [card-acquiring.md](card-acquiring.md) | Card collection orders, refund orders, dispute orders |
| Reports | [reports.md](reports.md) | Business report generation |
| System Admin | [system-admin.md](system-admin.md) | User management, role management, security center |
| Developer Center | [developer-center.md](developer-center.md) | API Key management, Webhooks callbacks |
