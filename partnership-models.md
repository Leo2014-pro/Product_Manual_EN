# Partnership Models


### API Mode

Suitable for technology-driven enterprises:
- Deep system integration
- Automated payment workflows
- Custom business logic

### SaaS Self-Hosted Mode

Suitable for enterprises with existing payment infrastructure:
- Self-managed funds
- Self-connected channels
- SaaS serves only as the system layer

### SaaS Hosted Mode

Suitable for rapid business launch:
- Platform-hosted settlement
- Quick go-live
- Reduced complexity
