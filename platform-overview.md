# Platform Overview

This platform is a Global Payment Infrastructure Platform that provides enterprises with the foundational capabilities needed to build payment systems.
The platform does not serve as a direct fund management tool; rather, it provides a complete payment infrastructure layer, including:
- Global collection network access
- Card payment and acquiring capabilities
- Card issuance capabilities
- Virtual account and ledger system
- Fund settlement and exchange capabilities
- Multi-channel routing and scheduling capabilities

Enterprises can rapidly build their own payment products and fund flow systems on top of this platform.
