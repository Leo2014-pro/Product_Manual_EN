# Crypto Card

### Module Definition

Used for issuing global payment cards, connecting to the consumer spending network.

### Capability Description

Supported features:
- Virtual Card
- Physical Card
- Visa / Mastercard networks
- Real-time card issuance / freeze / unfreeze
- Limit controls (Daily / Monthly Limit)

### Example (Advertising Campaigns)

- User tops up USDT
- Converts to USD
- Generates a Visa card
- Used for Google / Meta advertising campaigns
- Real-time deduction and recording
