# Settlement & Exchange

### Module Definition

Handles conversions between different fund systems.

### Dual-Mode Settlement

**Compliant Settlement Mode**
- Licensed institutions handle exchanges
- Fiat cross-border settlement
- Standard clearing paths

**Liquidity Pool Mode**
- Internal liquidity system
- Stablecoin bridging
- Real-time exchange

### Example (Cross-System Flow)

USD deposit → USD/USDT conversion → USD withdrawal
