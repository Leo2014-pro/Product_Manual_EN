# SaaS Management System

### Module Definition

A unified control center for managing all payment operations.

### Functional Modules

- Merchant Management System
- Transaction Management System
- Account Management System
- Card Management System
- Channel Management System
- API Management System
- Risk Control System

### Usage Modes

**SaaS Mode**
- Direct use of the backend system

**API Mode**
- Merchant role, integrated with business systems
